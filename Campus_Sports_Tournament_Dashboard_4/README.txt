CAMPUS SPORTS TOURNAMENT DASHBOARD — PHASE 1

HOW TO OPEN:
1. Extract the ZIP file into a folder.
2. Open the extracted folder.
3. Double-click index.html (or tap it and choose a browser).
4. Use the navigation bar to open the seven linked pages.

FILES:
index.html       Home Dashboard
schedule.html    Schedule & Standings
register.html    Team Registration
sports.html      Sports Categories
live-scores.html Live Match Center
results.html     Results & Prize Pool
admin.html       Admin Control Panel
style.css        Shared green sports theme
script.js        Demo form interactions

NOTE:
This is a front-end Phase 1 prototype. Forms show local demo confirmations only.
They do not save to a database, send emails, provide secure admin login, or connect
to real-time match scoring. Replace sample dates, scores, and prize details with
official college information before final submission.
